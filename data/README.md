# Dataset

This project uses the **Colon Tumor gene expression dataset** introduced by Alon et al. (1999).

- 62 samples (40 tumor, 22 normal)
- 2,000 gene-expression features

## How to obtain it

The dataset is not included in this repository due to size and licensing considerations.

You can obtain it from the following source:

- [Colon Tumor Gene Expression Dataset](https://pmc.ncbi.nlm.nih.gov/articles/PMC10621932/#sec006)
